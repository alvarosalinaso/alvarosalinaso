| Project / Proyecto | Description / Descripción |
|--------------------|---------------------------|
| [Portfolio Web](https://github.com/alvarosalinaso/portfolio-web) | **Vitrina principal**: 6 dashboards interactivos integrados (Chilean Games, Man United Performance, United Passing, Financial Audit, Gamer Simulator, Tactical CNA). Desplegado en GitHub Pages. **[Live](https://alvarosalinaso.github.io/portfolio-web/)** |
