### Proyectos

#### Historia + Datos

### Cómo trabajo

- **Datos reales, no ficticios**: Cuando uso datos sintéticos, lo digo. Cuando son reales, verifico la fuente.
- **Reproducible**: Docker, requirements.txt, tests. Si no corre dos veces, no sirve.
- **Documentación clara**: READMEs bilingües con metodología y hallazgos. No solo código.
- **Sin humo**: Si un método no funciona, lo digo. Si los datos son limitados, lo anoto.

### Projects

#### Personal Projects

- **[Manchester United: What happened after Ferguson?](https://github.com/alvarosalinaso/manchester-united-analisis)** — Causal analysis (Difference-in-Differences) of managerial changes. 32 Premier League seasons.

### How I Work

- **Real data, not fake**: When I use synthetic data, I say so. When it's real, I verify the source.
- **Reproducible**: Docker, requirements.txt, tests. If it doesn't run twice, it doesn't work.
- **Clear documentation**: Bilingual READMEs with methodology and findings. Not just code.
- **No buzzwords**: If a method doesn't work, I say it. If data is limited, I note it.
