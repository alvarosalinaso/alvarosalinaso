## Projects / Proyectos

Each project starts with a question that bugged me. / Cada proyecto empieza con una pregunta que me hizo ruido.

### Data + Historia / History + Data

### [Chile Geografía Histórica](https://github.com/alvarosalinaso/chile-geografia-historica)
Interactive map with 4 layers: presidents by birthplace, population by region (census 1907-2017), historical events, and provincial boundary evolution. GeoPandas + Folium. / Mapa interactivo con 4 capas: presidentes por nacimiento, población por región, eventos históricos y evolución de límites.

### [Chilean Video Games Market Analysis](https://github.com/alvarosalinaso/chilean-videogames-analysis)
ETL + clustering + ARIMA forecasting. 150 Chilean games on Steam/Itch.io. I analyzed prices, reviews, and revenue to understand the local indie market. / Analicé precios, reseñas y rentabilidad para entender el mercado indie chileno.

### [Chilean Political Discourse + NLP](https://github.com/alvarosalinaso/geopolitica-textual-nlp)
NER + sentiment on presidential speeches (1832-2000). spaCy for entity recognition, sentiment analysis, interactive Folium map. / NER + sentimiento sobre discursos presidenciales chilenos.

## How I Work / Cómo trabajo

- **Real data, not fake**: When I use synthetic data, I say so. When it's real, I verify the source. / Cuando uso datos sintéticos, lo digo. Cuando son reales, verifico la fuente.
- **Reproducible**: Docker, requirements.txt, tests. If it doesn't run twice, it doesn't work. / Si no corre dos veces, no sirve.
- **Clear documentation**: Bilingual READMEs with methodology and findings. Not just code. / READMEs bilingües con metodología y hallazgos.
- **No BS**: If a method doesn't work, I say it. If data is limited, I note it. / Si un método no funciona, lo digo.
